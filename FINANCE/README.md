# FINANCE_DESK | 재경관리 시스템

**반복되는 정산과 집계를 연결하고, 월별 재경 업무를 효율적으로 관리하다.**

## 1. 프로젝트 소개

급여, 지급결의서, 법인카드, 세금계산서 등 재경 업무는 서로 연관되어 있지만 관리 방식은 분리되어 있는 경우가 많습니다. 이로 인해 같은 정보를 반복해서 입력하거나, 여러 자료를 대조하고 집계하는 데 시간이 소요됩니다.

FINANCE_DESK는 이러한 문제를 줄이기 위해 기획한 **재경관리 시스템**입니다. 재경 업무의 주요 데이터를 연결하고, 반복적인 계산·분류·대사·집계를 자동화해 월별 마감 업무와 현황 관리를 효율적으로 수행하도록 설계했습니다.

## 2. 주요 기능

### ① 급여관리

* 사원 마스터에 등록된 기본급·수당을 바탕으로 근태 및 4대 보험 요율을 반영해 급여대장 계산
* 근속연수를 기준으로 연차를 간이 계산하는 기능 제공

### ② 지급결의서 관리

* 정기적으로 발생하는 지출처와 금액을 정기지급 마스터에 등록
* 결의일자를 변경하면 등록된 정기 지급 항목을 기준으로 결의서 내용 자동 갱신

### ③ 법인카드 관리

* 카드사 이용 내역 CSV 업로드
* 가맹점명 키워드를 기반으로 계정과목 자동 분류
* 카드번호별·계정과목별 사용 금액 집계

### ④ 세금계산서 대사

* 매입 세금계산서와 법인카드 사용 내역을 거래처명·금액 기준으로 비교
* 업무 관련 여부를 확인해 매입세액 불공제 검토 대상 분류 지원

### ⑤ 예산·실적 관리

* 급여·지급결의서·법인카드 데이터를 활용한 계정과목별 실적 집계
* 예산 대비 실적 및 집행률 확인

### ⑥ 권한 및 이력 관리

* 경영지원팀과 일반 직원의 권한을 구분
* 일반 직원은 본인의 급여명세서를 조회하고 인쇄할 수 있도록 구성
* 급여대장 및 지급결의서 마감 시점의 데이터를 스냅샷으로 저장
* 저장된 마감 이력을 기준으로 월별 상세 내역 조회

## 3. 핵심 설계 포인트

* **업무 흐름 연결:** 급여·지출·카드 사용·세금계산서 데이터를 연계
* **반복 업무 자동화:** 정기 지급, 계정과목 분류, 금액 집계 등 반복 작업 최소화
* **대사 효율화:** 서로 다른 자료를 기준에 따라 비교해 검토 대상 확인 지원
* **마감 이력 관리:** 마감 시점의 데이터를 저장해 과거 내역을 확인할 수 있도록 설계
* **권한 분리:** 사용자 역할에 따라 조회할 수 있는 정보와 기능 구분

## 4. 프로젝트 정보

* **프로젝트 유형:** 개인 프로젝트 · 포트폴리오

* **주요 범위:** 대시보드, 급여관리, 지급결의서, 법인카드, 세금계산서 대사, 예산·실적, 이력조회

> 급여·보험·세무 관련 기능은 포트폴리오 목적의 참고용 구현입니다. 실제 회계 처리나 세무 신고에 활용하기 전에는 관련 법령, 증빙 및 회계·세무 기준을 확인해야 합니다.
