# ERP | 경영지원 업무 통합 및 자동화 프로젝트

경영지원 업무를 하나의 시각으로 바라보고, 반복적인 수작업을 줄이기 위해 설계한 개인 프로젝트입니다.

기존 실무에서는 인사·회계·총무 관련 정보가 여러 엑셀 파일로 분산되어 관리되는 경우가 많았습니다. 정보가 변경될 때마다 여러 파일을 수정해야 했고, 반복적인 업무와 담당자 변경에 따른 인수인계 부담도 발생했습니다.

이러한 문제에서 출발해 **경영지원 업무를 통합적으로 관리하는 ONE-DESK**, 인사총무 업무에 집중한 **HR_ASSISTANT**, 재경 업무의 정산과 집계를 자동화한 **FINANCE_DESK**를 설계했습니다.

## 프로젝트 구성

### 01. ONE-DESK | 경영지원 통합 플랫폼

경영지원 업무를 하나의 플랫폼에서 연결해 관리하는 통합형 시스템입니다.

* **대시보드:** 인사·회계·재고 등 주요 운영 현황 요약
* **인사관리(HRM):** 급여·근태·연차 관리
* **전자결재:** 사내 결재 프로세스 관리
* **회계·지출증빙:** 지출 내역 및 증빙 관리
* **고객·영업(CRM):** 고객 및 영업 데이터 관리
* **재고·자산관리:** 비품·자산 현황 및 감가상각 관리
* **권한별 화면:** 일반 직원과 경영지원팀의 접근 범위 구분

🔗 [ONE-DESK 바로가기](https://mylogspace.github.io/ERP/ONE_DESK/)

### 02. HR_ASSISTANT | 인사총무 업무 자동화

반복적인 인사 계산과 운영 업무를 자동화하고, 인사 데이터를 활용한 분석 기능까지 확장한 웹 애플리케이션입니다.

* **근태·연차:** 지각 여부 및 잔여 연차 자동 계산
* **급여·정산:** 급여대장, 중도 입·퇴사자 일할 계산, 퇴직금 및 연말정산 추정
* **자산·총무:** 비품 교체 예정일 및 확인 필요 여부 관리
* **피플 인사이트:** 인사평가, 퇴사 위험도 예측, 직원경험 감정 분석, 근태 이상징후 분석
* **사내규정 FAQ:** 연차·경조사비·비품 신청 등 자주 묻는 질문에 응답

🔗 [HR_ASSISTANT 바로가기](https://mylogspace.github.io/ERP/HR_ASSISTANT/)

### 03. FINANCE_DESK | 재경관리 시스템

급여, 지급결의, 법인카드, 세금계산서 및 예산 데이터를 연결해 반복적인 정산·집계 업무를 자동화한 시스템입니다.

* **급여관리:** 기본급·수당·근태·보험 요율 기반 급여 계산
* **지급결의서:** 정기 지급 항목을 활용한 결의서 자동 갱신
* **법인카드:** CSV 업로드, 계정과목 자동 분류 및 사용 내역 집계
* **세금계산서 대사:** 카드 사용 내역과 매입 세금계산서 비교
* **예산·실적:** 계정과목별 예산 대비 실적 및 집행률 확인
* **권한·이력관리:** 권한별 조회 범위 분리 및 마감 데이터 이력 조회

🔗 [FINANCE_DESK 바로가기](https://mylogspace.github.io/ERP/FINANCE)

## 기획 방향

| 구분  | 핵심 목표                      |
| --- | -------------------------- |
| 통합  | 분산된 업무 정보와 관리 흐름을 하나로 연결   |
| 자동화 | 반복적인 계산·입력·집계 작업 최소화       |
| 표준화 | 담당자가 변경되어도 일관된 방식으로 업무 관리  |
| 가시화 | 필요한 현황과 이력을 빠르게 확인         |
| 확장  | 통합 관점에서 출발해 업무별 상세 기능으로 발전 |

## 프로젝트 정보

* **프로젝트 유형:** 개인 프로젝트 · 포트폴리오
* **프로젝트 범위:** 경영지원 통합, 인사총무 자동화, 재경관리
* **개발 방향:** 실무 문제 정의 → 업무 프로세스 설계 → 기능 구현
* **운영 목적:** 경영지원 업무의 효율성과 관리 편의성을 높이는 서비스 설계 및 구현 역량을 보여주기 위한 프로젝트

각 플랫폼은 경영지원 실무에서 발견한 불편함을 바탕으로 기획한 포트폴리오용 프로젝트입니다.
