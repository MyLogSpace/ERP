# HR_ASSISTANT | 인사총무 업무 자동화 웹앱

**반복적인 인사 계산은 자동화하고, 인사 데이터는 운영과 분석에 활용하다.**

## 1. 프로젝트 소개

인사총무 업무에는 근태와 연차 계산, 급여 정산, 자산 관리처럼 반복적으로 처리해야 하는 작업이 많습니다. 특히 중도 입·퇴사자 급여 계산이나 정기적인 데이터 갱신은 수작업 부담이 크고, 담당자에 따라 처리 방식이 달라질 수 있습니다.

HR_ASSISTANT는 이러한 반복 업무를 자동화하고, 인사 데이터를 활용한 분석 기능까지 확장하기 위해 기획한 **인사총무 업무 자동화 웹 애플리케이션**입니다.

## 2. 주요 기능

### ① 근태 및 운영 관리

* **근태·연차 관리:** 출근 시각과 사용 연차를 입력하면 지각 여부 및 잔여 연차 자동 계산

### ② 급여 및 정산 자동화

* **급여대장:** 기본급을 기준으로 4대 보험 공제액과 실수령액 계산, 보험 요율 수정 지원
* **중도 입·퇴사 일할 계산기:** 입사일·퇴사일을 기준으로 세전 급여 및 4대 보험 일할 정산액 산출
* **퇴직금·퇴직연금:** 근속연수 기반 퇴직금 추정액과 DC형 퇴직연금 연간 적립액 계산
* **연말정산·보수총액신고:** 연간 소득세 및 고용·산재보험료 정산 금액 추정

### ③ 자산 및 총무 관리

* **자산·비품 관리:** 지급일자와 교체주기를 기준으로 교체 예정일 및 확인 필요 여부 계산

### ④ 피플 인사이트

* **인사평가:** 목표달성도와 역량평가 점수를 활용한 종합등급 산출 및 전기 대비 등급 변동 관리
* **퇴사 위험도 예측:** 근태·평가·보상 데이터를 활용한 로지스틱 회귀 기반 위험도 산출
* **직원경험 분석:** 주간 펄스 서베이 응답을 키워드 기반으로 분석해 감정 및 몰입도 흐름 확인
* **근태 이상징후 분석:** 12~16주간의 근태 데이터를 분석해 번아웃 위험군 및 이탈 징후 패턴 탐지

### ⑤ 사내 지원 서비스

* **사내규정 FAQ 챗봇:** 연차·경조사비·비품 신청 등 자주 묻는 질문에 키워드 매칭 방식으로 응답

## 3. 핵심 설계 포인트

* **계산 자동화:** 반복적인 수작업 계산을 입력 기반 자동 계산으로 전환
* **업무 표준화:** 정해진 계산 기준과 입력 항목을 통해 일관된 처리 방식 제공
* **운영과 분석의 연결:** 단순 관리 기능을 넘어 인사 데이터를 활용한 분석 기능으로 확장
* **실용적인 접근:** 인사총무 실무에서 자주 발생하는 문제를 중심으로 기능 구성

## 4. 프로젝트 정보

* **프로젝트 유형:** 개인 프로젝트 · 포트폴리오
* **서비스 유형:** SPA 기반 인사총무 업무 자동화 웹 애플리케이션
* **주요 범위:** 근태·연차, 급여·정산, 자산·총무, 피플 인사이트, 사내 지원 서비스

> 급여·세금·보험 관련 계산 및 예측 기능은 포트폴리오 목적의 참고용 구현이며, 실제 신고나 인사 의사결정에 활용하기 전에는 적용 법령과 산정 기준을 별도로 확인해야 합니다.
