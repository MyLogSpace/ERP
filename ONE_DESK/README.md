# ONE-DESK | 경영지원 통합 플랫폼

**흩어진 경영지원 업무를 하나의 화면과 데이터 흐름으로 연결하다.**

## 1. 프로젝트 소개

인사, 회계, 총무, 영업 등 경영지원 업무는 담당자와 업무 영역에 따라 여러 엑셀 파일이나 개별 도구로 분산되어 관리되기 쉽습니다.

이러한 구조에서는 정보가 변경될 때 여러 파일을 각각 수정해야 하고, 담당자가 바뀌면 업무 현황과 처리 방식을 다시 파악해야 하는 불편함이 발생합니다.

ONE-DESK는 이러한 문제를 해결하기 위해 기획한 **경영지원 통합 플랫폼**입니다. 회사 운영에 필요한 주요 업무를 하나의 플랫폼 안에서 연결하고, 경영지원팀이 전체 현황을 효율적으로 파악할 수 있도록 설계했습니다.

## 2. 주요 기능

| 업무 영역      | 주요 기능                       |
| ---------- | --------------------------- |
| 대시보드       | 인사·회계·재고 등 주요 운영 현황 요약      |
| 인사관리(HRM)  | 급여·근태·연차 등 인사 데이터 관리        |
| 전자결재       | 사내 결재 프로세스 및 결재 현황 관리       |
| 회계·지출증빙    | 지출 내역과 증빙 정보 관리             |
| 고객·영업(CRM) | 고객 정보 및 영업 데이터 관리           |
| 재고·자산관리    | 비품·자산 현황 및 감가상각 관리          |
| 권한별 화면     | 일반 직원과 경영지원팀의 화면 및 접근 범위 구분 |

## 3. 핵심 설계 포인트

* **업무 통합:** 여러 업무 영역을 하나의 플랫폼에서 확인할 수 있도록 구성
* **데이터 연결:** 업무별 정보가 분리되어 관리되는 문제를 줄이기 위한 통합 데이터 구조 설계
* **권한 구분:** 사용자 역할에 따라 필요한 기능과 정보에 접근하도록 구성
* **업무 가시성:** 여러 파일을 열어 확인하지 않아도 주요 운영 현황을 파악할 수 있도록 설계

## 4. 프로젝트 정보

* **서비스 유형:** SPA 기반 경영지원 통합 웹 애플리케이션
* **주요 범위:** 대시보드, HRM, 전자결재, 회계·지출증빙, CRM, 재고·자산관리
